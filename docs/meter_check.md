# 変拍子の判定 確認リスト（v0.1.41、ユーザー確認 2026-11-04・v0.1.42 の結果を追記）

v0.1.41 から、ループが 4/4 の小節で割り切れる曲でも変拍子を判定する（4/4 以外の小節が 3 小節以上続くときだけ）。
ランダムに選んだ 160 タイトル（各 1〜3 曲目）のうち、割り切れるループ 206 曲中 16 曲で変拍子と判定された。
これが正しいかを聴いて確認してほしい。

- MIDI: `morokoshi\tmp\meter_check\`（変換ログ `*.log` も同じフォルダ）
- 拍の位置は MIDI の拍（4 分音符）で、曲の頭から数える（前奏を含む）。「@」の位置からその拍子
- 曲全体が 1 つの拍子の判定（「全体」）は、曲がもともと 3 拍子・6/8 などの可能性もある
- 不要なら「変拍子を検出する」をオフ（CLI: `--no-odd-meter`）

ユーザーの補足: 3 連符ノリの曲を 4/4 と 6/8（12/8）のどちらにするかはどちらでも良い。ただし急に 6/8 が 4/4 になる曲もあるので注意。
アウフタクトは最初は人間にも分からないことが多く、後ろを聴いて拍の頭を認識してから「あれはアウフタクトだった」と分かる。
アウフタクトが 1 拍で割り切れないときは、頭に休符を入れて割り切れるようにする。
